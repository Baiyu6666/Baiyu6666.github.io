Supervised Student Projects

Student projects I have supervised at the Learning Algorithms and Systems Laboratory (LASA), EPFL, exploring how robots can learn constraints from demonstrations and use them for motion planning and control.

Albert Árboles

Learning Equality Constraints from Demonstrations

Learns geometric constraint surfaces from demonstrated trajectories using a neural model. Projection-based corrections and optimal control then generate robot motions that stay on the learned surface while moving toward new goals.

Report (PDF)

Marcus Hughes Edjolo

LLM-guided Constraint Learning from Demonstration

Semester project · Spring 2026

Uses a large language model to propose relevant variables and constraint forms from a natural-language task, then fits numerical boundaries from a safe demonstration and synthetic unsafe examples. The resulting explicit inequalities are evaluated in a model predictive control trajectory planner.

Report (PDF)

Vincent Guilherme Bouzereau

Model Predictive Control for Constraint Learning from Expert Demonstrations

Semester project · Spring 2026

Integrates constraints learned through Positive-Unlabeled Constraint Learning (PUCL) into a model predictive control planner as explicit inequalities. Simulation experiments study obstacle avoidance, generalization to new starts and goals, and how the planner's exploration affects constraint learning.

Report (PDF)

Erfan Etesami

Constraint Learning with Inverse Reinforcement Learning

Investigates how to recover unknown state and action constraints from expert demonstrations when the task reward is known. The project alternates policy optimization and constraint inference, exploring neural classifiers and Gaussian mixture models to identify feasible regions.
